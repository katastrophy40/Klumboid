How to Play & Load Games

Option A: Repo Launcher

  1. Select Repo Launcher in the top bar.
  2. Browse the catalog fetched live from GitHub.
  3. Click Play Now on any item to run it instantly in the player.
  4. Change the target repository anytime using the top input field.

Option B: Drive & Local Loader

  1. Click Download to grab game zip files from Google Drive.
  2. Extract the .zip file on your computer.
  3. Switch to Local Loader mode in the toolbar.
  4. Click Choose File and select your index.html.
