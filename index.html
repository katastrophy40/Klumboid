Instructions

1. Local Source Package

  1. Click Download to access the repository folder.
  2. Click the option menu beside the directory name and select Download.
  3. Extract the archive onto your system.

2. Load HTML File

  1. Click Choose File in the top toolbar.
  2. Select your target .html file.
  3. Alternatively, click Switch to Index to load direct files from the repository list.
